4. Weights

new weight = old weight + learning rate × error × sentence dimension.

A weight is learned importance. Positive weights push the prediction up. Negative weights push the prediction down.

6. Error

Press Enter to compare the target with the sigmoid output.

Error tells training how far the prediction was from the target and which direction to move.

7. Conceptual Explanation for the Current Step

Press Enter. MAGPAI will process one example, make a prediction, compare it to the target, then slightly change the weights and bias.

Formula used in this educational demo: z = w·x + b, prediction = sigmoid(z), error = target - prediction, update = learning_rate × error × input.
