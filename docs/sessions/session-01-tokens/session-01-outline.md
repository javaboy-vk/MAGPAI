# MAGPAI – Session 01 – Text to Tokens to Vectors – v1.0

## Purpose

Explain how MAGPAI fits in the AI/ML stack, then show how a business question becomes tokens, token IDs, vectors, an input tensor, and a chart-backed answer.

## Delivery Flow

1. Open MAGPAI as an inspectable AI-under-the-covers learning lab.
2. Position Session 1 at the NLP and language modeling layer of the AI/ML stack.
3. Show the math, science, and engineering disciplines underneath the AI/ML layers.
4. Narrow to the Session 1 topic: text becoming numeric model input.
5. Carry the canonical question through tokenization, vocabulary lookup, embeddings, vectors, tensors, and chart-backed answer generation.

## Core Takeaway

AI systems do not process business language as raw words. The system converts text into structured numeric representations, then uses code, data, and tools to produce an inspectable answer.
