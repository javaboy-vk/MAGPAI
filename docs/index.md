# MAGPAI – MAG Prototype AI

MAGPAI is a transparent educational AI lab for explaining how AI works under the covers.

It combines:

- documentation pages
- diagrams
- Python source code
- notebooks
- visual runtime demos
- Streamlit apps
- FastAPI local services

## Core Principle

MAGPAI treats AI as inspectable software.

The goal is to show tokens, tensors, predictions, loss, attention, inference flow, and runtime metrics in a way that engineers can see and understand.
