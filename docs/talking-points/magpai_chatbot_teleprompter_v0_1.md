# MAGPAI Chatbot Teleprompter - v0.1

We are going to start by locating MAGPAI in the larger AI/ML stack.

MAGPAI starts in the language layer: the place where text becomes tokens, token IDs, vectors, tensors, and eventually model input.

That language layer depends on the layers below it: computing, mathematics, data, classical machine learning, and deep learning.

It also depends on specific disciplines: linear algebra, probability, statistics, optimization, information theory, linguistics, and software systems.

Now we can narrow the scope to Session 1.

We are going to ask a simple business question:

are MAG sales up in Chicago?

MAGPAI will answer the question, generate a chart, and then we will rewind.

The important part is not only the answer. The important part is that we will open the box and inspect the path from text to computation.

We will see the text become tokens.

We will see the tokens become vectors.

We will see the vectors enter a tiny neural network.

We will see the model detect intent, identify Chicago as the location, retrieve sales data, and generate a response.

This is why MAGPAI is useful for this learning series. It is not just a chatbot. It is a microscope for understanding how AI works under the covers.
