# MAGPAI AI Glossary – v1.0

## Token

A unit of text processed by a model.

## Embedding

A numeric vector representation of a token.

## Logits

Raw model scores before conversion to probabilities.

## Softmax

A function that converts logits into probabilities.

## Loss

A numeric measure of prediction error.

## Attention

A mechanism that lets tokens assign importance to other tokens.

## Inference

Using a trained model to generate outputs.

## Training

Updating model weights using examples and loss feedback.
