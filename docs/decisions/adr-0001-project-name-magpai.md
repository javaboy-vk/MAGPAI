# ADR 0001 – Project Name MAGPAI

## Status

Accepted

## Decision

The tiny educational AI model and lab project will be named MAGPAI.

## Meaning

MAGPAI means MAG Prototype AI. MAG is a fictitious company that sells products in Chicago.

It is pronounced magpie.

## Rationale

The name is memorable, aligns with the MAG naming convention, and clearly signals AI while avoiding claims of production maturity.
