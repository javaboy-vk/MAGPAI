# MAGPAI – Mark Anthony Group Prototype AI – v1.0

**Pronounced:** magpie

MAGPAI is a tiny, transparent educational AI model and demo lab.

It exists to explain how AI works under the covers through practical engineering demonstrations.

## What MAGPAI Is

MAGPAI is:

- a learning platform
- a demo series
- a tiny model
- a visual runtime lab
- a documentation system
- a bridge from theory to engineering practice

## What MAGPAI Is Not

MAGPAI is not:

- a production model
- a commercial AI platform
- a replacement for approved enterprise AI systems
- a place for sensitive company data

## Demo Philosophy

Each demo should include:

1. slides
2. diagrams
3. Python source code
4. runtime visualization
5. clear engineering takeaway

## Core Message

AI is software we can inspect, run, measure, explain, and govern.
