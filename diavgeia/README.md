## Purpose

MAGPAI is a hands-on AI learning and demo lab for explaining how modern AI systems work under the covers.

It is designed to become an internal engineering learning path with:

- concept notes
- session outlines
- architecture diagrams
- source code references
- demo scripts
- runtime observations
- lessons learned
- decision records

MAGPAI treats AI as inspectable software.

The goal is to help engineers see and understand tokens, vectors, tensors, probabilities, training feedback, attention, local inference, observability, and enterprise safety boundaries.
