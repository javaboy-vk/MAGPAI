# Demo 20.B - Neural Network Training v2

## Say This

This second version shows the same learning idea in a more dashboard-like view.

Each press of `Enter` processes one training sentence.

After each step, MAGPAI re-evaluates the same business question:

```text
Are MAG sales up in Chicago?
```

The answer changes because the learned parameters change.

The key learning objects are:

```text
training sentence
target
input tensor
learned weights
learned bias
updated answer
```

This is a small teaching neural network, but it demonstrates the training loop that larger systems also depend on.

## Demo Action

Open Neural Network Training v2.

Press `Enter` through the training examples.

Point out:

- The training-progress counter.
- The current training example.
- The tensor MAGPAI sees.
- The learned weights after the current step.
- The learned bias after the current step.
- The answer after this step.

At the final step, emphasize that the model has learned from all six examples in the demo.

## Key Points

- Training is iterative.
- Each example updates the learned parameters.
- Weights and bias are visible in this demo.
- The same question is re-answered after each update.
- Version 2 makes the training loop easier to inspect.
