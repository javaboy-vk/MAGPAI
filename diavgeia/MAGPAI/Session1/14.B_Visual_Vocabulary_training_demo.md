# Demo 14.B - Visual Vocabulary Training Demo

## Slide Intent

Show that the tokenization idea also applies to images: pixels become visual tokens, visual token IDs become embeddings, and the embeddings enter the neural network.

This demo corresponds to the site demo:

```text
docs/demo/vision_vocabulary_demo_v1_1.html
```

## Say This

The previous demo used text.

Now we will use an image.

The input is different, but the conceptual path is similar:

```text
image -> visual tokenizer -> visual token IDs -> embeddings -> neural network -> prediction
```

The computer does not begin with the idea of a bird.

It begins with pixels.

The vision tokenizer divides the image into patches and maps important visual patterns to a learned visual vocabulary.

For this teaching demo, the visual vocabulary includes concepts like:

```text
Black Feather
White Feather
Beak
Eye
Wing
Tail
Branch
Sky / Background
```

Those visual concepts receive IDs, just like text tokens receive IDs.

Then each visual token ID selects an embedding vector.

The neural network receives the embedding tensor and uses those learned visual patterns to predict the class.

## Demo Action

Open the visual vocabulary training demo.

Press `Enter` to advance through the steps.

Pause at these moments:

- The image is divided into visual patches.
- The visual vocabulary gives patch patterns stable IDs.
- The detected visual tokens become an ID sequence.
- The ID sequence becomes an embedding tensor.
- The neural network predicts `MAGPIE`.

This is the visual version of the same idea we used for text.

The model is not reading words at this point, and it is not seeing a bird the way a person does.

It is operating on learned numeric representations.

## Transition

Now that both text and images have reached embeddings, we can return to the language-model path.

The next step is to show that embedding vectors become the live numeric input flowing into the neural network.

## Key Points

- Images can be tokenized too.
- Visual tokens are learned patterns from image patches.
- Visual token IDs retrieve embedding vectors.
- The embedding tensor becomes neural-network input.
- Text models and vision models share the same high-level pattern: tokens become vectors, and vectors feed the network.
