# Demo 20.C - Vision Neural Network Training

## Slide Intent

Show the vision neural-network demo where visual tokens activate learned connections and produce a prediction.

This demo corresponds to the site demo:

```text
docs/demo/vision_neural_network_demo_v1_11.html
```

## Say This

The previous demos used text and business examples.

Now the input is visual.

The path is still recognizable:

```text
image patches -> visual tokens -> embeddings -> neural-network activations -> prediction
```

The demo draws learned associations one connection at a time.

Each connection has a numeric activation strength.

That number comes from comparing a source vector with a learned weight vector, then applying the model's calculation.

So again, the model is operating on numbers.

The visual result is useful for us, but the network itself is using learned vectors, weights, bias, and activations.

## Demo Action

Open Vision Neural Network Training.

Press `Enter` to draw the next learned connection.

Pause at:

- The visual token being used.
- The connection drawn from that token.
- The dot-product style calculation.
- The activation value.
- The output prediction.

Use `Esc` if you need to restart the sequence.

## Transition

Now we can move from individual model mechanics to the user-facing application: a chatbot that runs the question-to-answer path.

## Key Points

- Vision models also use learned numeric representations.
- Visual tokens activate learned neural-network connections.
- Connection strength is numeric.
- The prediction comes from accumulated learned evidence.
- Text and vision demos share the same conceptual pattern: tokens become vectors, vectors activate a network.
