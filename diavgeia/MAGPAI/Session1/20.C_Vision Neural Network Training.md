## Say This

The previous demos used text and business examples.

Now the input is visual.

The path is still recognizable:

```text
image patches -> visual tokens -> embeddings -> neural-network activations -> prediction
```

The demo draws learned associations one connection at a time.
Each connection has a numeric activation strength.
That number comes from comparing a source vector with a learned weight vector, then applying the model's calculation.
So again, the model is operating on numbers.
The visual result is useful for us, but the network itself is using learned vectors, weights, bias, and activations.

## Hidden Layers

**Hidden layers** are the internal processing layers between the input tokens and the final prediction.

In the vision demo, the flow is roughly:

image patches -> visual tokens -> hidden layer 1 -> hidden layer 2 -> output prediction
The hidden neurons are not the original image and not the final answer. They are learned feature detectors.

For example:

Input layer: visual tokens from image patches, such as beak, wing, eye, body, background.
Hidden layer 1: detects smaller visual features, such as edges, colors, pointed shapes, texture.
Hidden layer 2: combines those into larger concepts, such as head + beak, wing + body, bird-like shape.
Output layer: uses the accumulated evidence to predict the class, such as MAGPIE.
For the line from the input circle to N1.1: the neural network does not “choose to draw a line” in the human sense. 
My demo draws the line to show one learned connection.

The actual calculation is:

activation = input_vector dot weight_vector + bias
So for the first connection:

Token / patch vector -> compared with N1.1 learned weights -> activation strength
N1.1 has learned weights that respond strongly to a particular visual pattern. In the demo source, the first shown connection is from token T3 to N1.1, described as a beak edge / pointed object detector. That means the image patch contains beak-like evidence, and N1.1 is the hidden neuron whose learned weights match that evidence.

Important distinction:

In a real neural network, all these connections are evaluated mathematically. 
Stronger activations matter more; weaker activations matter less.

In my demo, the line is drawn step-by-step so we can see the process. 
My goal is to visualize: “this input feature strongly activates this hidden neuron.”



## Why T7 links to N1.3 and not N1.4
Because N1.3 and N1.4 represent different learned feature detectors in the demo.

N1.3 is associated with:

dark feather texture
foreground/background separation
N1.4 is associated with:

white feather patch
bright plumage patches
black-white contrast pattern
So T7 = Branch goes to N1.3 because the branch is useful for separating the bird from the background. It is not mainly a bright white plumage patch, so it does not fit the teaching role of N1.4.

In neural-network terms:

activation = input_vector dot weight_vector + bias
The branch vector matches N1.3’s learned weights better than N1.4’s learned weights for this demo step.

Plain English:

N1.3 helps decide “what is bird edge vs natural background.”
N1.4 helps detect “white feather / bright plumage.”
A branch is background context, so it belongs with N1.3, not N1.4.
