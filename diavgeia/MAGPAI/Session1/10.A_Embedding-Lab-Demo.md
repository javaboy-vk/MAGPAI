# Demo 10.A - Embedding Lab Demo

## Slide Intent

Use the lab to connect a multidimensional vector to a simple 2D Cartesian diagram.

The goal is not to say that embeddings only have two dimensions. The goal is to show the intuition: each dimension is like a coordinate, and changing the text changes the coordinate values.

## Say This

We just said that a vector is a list of numbers.

Now we will make that visible.

In the real embedding, the vector can have many dimensions:

```text
sales = [-0.62, 0.18, 0.45, -0.09]
```

That is hard to draw directly, because four dimensions are already beyond a normal flat picture.

So in the lab, we use a 2D Cartesian diagram as a simplified view.

```text
x-axis = one selected vector dimension
y-axis = another selected vector dimension
```

The arrow starts at zero and points to the coordinate created by those two values.



## Demo Action

Change the text in the lab.

Watch the arrow move.

When the text changes, the token vectors change. When the vector values change, the arrow changes direction and length.

That visual movement is the important concept.

The vector dimensions behave like geographical coordinates in a multidimensional space.

In geography, a city can be located with latitude and longitude.

In embeddings, a word or phrase is located by many learned coordinates.

The 2D diagram is only a window into that larger space.

A 2D arrow is not the real vector.

It is only a visual approximation.

The real embedding may have 6, 128, 768, 1536, or thousands of dimensions. When we draw it on a 2D diagram, we are compressing it so humans can see it.

The algorithm is called dimensionality reduction or projection.

You are starting with a 6-dimensional vector:
But a Cartesian diagram can only show 2 dimensions
Projection is very much a Linear Algebra concept.
Dimensionality reduction uses Linear Algebra heavily, but it can also include statistics and machine learning.


## Transition

Now that the vector has a visible direction, we can zoom into Token ID 3 and show exactly how it becomes the `sales` vector.



## Key Points

- A multidimensional vector is a location in a numeric space.
- A 2D Cartesian diagram can show two selected dimensions at a time.
- The arrow direction comes from the vector coordinate values.
- Changing the text changes the vectors, so the arrows move.
- Embedding dimensions behave like learned coordinates of meaning.
