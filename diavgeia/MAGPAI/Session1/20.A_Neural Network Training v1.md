# Demo 20.A - Neural Network Training v1

## Slide Intent

Show the first neural-network training demo where one training example at a time changes weights and bias.

This demo corresponds to the site demo:

```text
docs/demo/MAGPAI_Weight_Bias_Visual_Trainer_v1.0.html
```

## Say This

We have now seen the full question-to-insight path.

This demo zooms into the learning step.

The neural network begins with weights and bias values.

For each training example, MAGPAI does four things:

```text
input tensor -> prediction -> compare with target -> adjust weights and bias
```

The point is not that this tiny model is production AI.

The point is that training is visible.

The model makes a prediction, sees how wrong it was, and slightly changes its internal numbers.

Those internal numbers are the learned weights and bias.

## Demo Action

Open Neural Network Training v1.

Press `Enter` or use the next-step button.

Pause at these moments:

- The tensor enters MAGPAI.
- The sentence vector is calculated.
- The linear score uses weights, vector, and bias.
- The prediction is compared to the target.
- The weights and bias update.

After a few steps, point out that the same fixed question is re-answered after the model has learned from more examples.

## Transition

Now we will move to the second neural-network training demo, which presents the same idea with a more complete training-progress view.

## Key Points

- Training changes weights and bias.
- Each example has an input and a target.
- Prediction error drives the update.
- The model's answer can change after training.
- This is the neural-network training part of the MAGPAI pipeline.
