# Demo 20.A - Neural Network Training v1

## Slide Intent

Show the first neural-network training demo where one training example at a time changes weights and bias.

This demo corresponds to the site demo:

```text
docs/demo/MAGPAI_Weight_Bias_Visual_Trainer_v1.0.html
```

## Say This

We have now seen the full question-to-insight path.

This demo zooms into the learning step.

The neural network begins with weights and bias values.

For each training example, MAGPAI does four things:

```text
input tensor -> prediction -> compare with target -> adjust weights and bias
```

The point is not that this tiny model is production AI.

The point is that training is visible.

The model makes a prediction, sees how wrong it was, and slightly changes its internal numbers.

Those internal numbers are the learned weights and bias.

# 7 top indicators
**Fixed Question Prediction** = the current predicted answer/confidence for “Are MAG sales up in Chicago?” after the model has trained on the examples seen so far.

**Fixed Question Loss** (final prediction confidence) is the error score for the fixed question: Are MAG sales up in Chicago?

It measures how far the model’s current prediction is from the expected target answer for that fixed question.
In the demo, the target is 1, meaning YES, sales are up. The formula is:
Low loss means the model is close to the expected answer; high loss means it is still wrong or uncertain.

Fixed Question Loss = 0.5 × (target - fixed_question_prediction)^2
So if the model predicts 0.80, then:
0.5 × (1 - 0.80)^2 = 0.02

The training process stops because we define a stopping rule.
A common stopping rule is based on loss:  prediction -> compare with target -> calculate loss
If the loss becomes small enough, training can stop.
We stop training when the prediction is close enough to the target and the loss is low enough.


**Training Example Prediction** is the model’s prediction for the current training sentence,
before or during the training update for that example.
Given this specific training sentence, what does the model currently predict before it compares 
that prediction to the known target?”
The model currently thinks this example supports “YES, sales are up” with confidence x.xx

**Error** = target - training_example_prediction


## Demo Action

Open Neural Network Training v1.

Press `Enter` or use the next-step button.

Pause at these moments:

- The tensor enters MAGPAI.
- The sentence vector is calculated.
- The linear score uses weights, vector, and bias.
- The prediction is compared to the target.
- The weights and bias update.

After a few steps, the same fixed question is re-answered after the model has learned from more examples.
