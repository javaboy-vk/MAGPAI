# Demo 8.A - Tokenizer Lab Demo

## Say This

We just defined a tokenizer as the component that turns raw text into known pieces.

Now we will make that visible.

The demo starts with this question:

```text
Are MAG sales up in Chicago?
```

The tokenizer normalizes the text and splits it into tokens:

```text
are
mag
sales
up
in
chicago
?
```

Then each token receives a token ID.

The important point is that the model is no longer looking at a sentence as a sentence.

It is looking at an ordered sequence of known text pieces.

## Demo Action

Open the Tokenizer Lab demo.

Change the input sentence.

Point out four panels:

- Normalized Text
- Tokens
- Token IDs
- Token Table

Use the default sentence first, then type a word that is not in the tiny demo vocabulary.

When the token is unknown, the teaching demo generates an ID so the audience can see the difference between known vocabulary tokens and generated teaching IDs.

## Transition

Now that the text has become tokens, the next step is to map each token to a token ID.

## Key Points

- Tokenization is the first conversion step.
- The tokenizer normalizes text before lookup.
- Tokens become token IDs.
- The demo vocabulary is deliberately tiny so the behavior is visible.
- Tokenization prepares the text; it does not answer the question.
